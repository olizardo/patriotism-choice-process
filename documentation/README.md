## Project Overview

This repository contains all code, data-preparation pipelines, and documentation for replicating the analyses in *Patriotism as a Choice Process: National Pride After 9/11*. The paper adjudicates between two competing theoretical frameworks for understanding national pride following the September 11 attacks and the post-9/11 period (2001–2004):

1. **Needs-based / Irrational Patriotism**: Predicts lower-status individuals experience increased national pride
2. **Choice-Process Theory** (Lawler, 1992): Predicts higher-status, autonomous individuals—especially those in nested voluntary associations—experience stronger increases

Using nationally representative data from the General Social Survey (GSS) in 1996 and 2004, the paper supports the choice-process framework, showing that education and voluntary-association membership predict the largest post-9/11 increases in national pride.

## Replication Instructions

### Prerequisites

#### 1. R & Required Packages
The project uses R 4.5.3 (or later). Required packages are managed via `renv` for reproducibility.

**Option A: Restore the project environment (recommended)**
```r
# In R, at the project root:
renv::restore()
```

This installs all packages to the exact versions captured in `renv.lock`, ensuring byte-for-byte reproducibility of model fits and table output.

**Option B: Install packages manually**
If `renv::restore()` fails, install the key packages directly:
```r
install.packages(c(
  "gssr",           # GSS data access
  "dplyr",          # Data wrangling
  "tidyr",          # Reshaping
  "modelsummary",   # Publication-ready tables
  "tinytable"       # Table formatting backend for modelsummary
))
```

#### 2. LaTeX (for compiling manuscript)
To compile the `.tex` manuscript locally, install a complete LaTeX distribution:
- **Linux (Debian/Ubuntu):** `apt-get install texlive-full` or `apt-get install texlive-science` (for `siunitx` package)
- **macOS:** Install [MacTeX](https://tug.org/mactex/)
- **Windows:** Install [MiKTeX](https://miktex.org/) or [TeXLive for Windows](https://tug.org/texlive/)

### Running the Replication Pipeline

Execute the canonical data-cleaning and model-fitting script:

```r
source("scripts/generate_tables.R")
```

This script:
1. **Fetches live GSS data** via `gssr::gss_get_yr(1996)` and `gss_get_yr(2004)`
2. **Cleans variables:**
   - Dichotomizes 10 "very proud" items (0–10 U.S. Pride scale)
   - Constructs Nationalism scale (mean of 4 reverse-coded 1–5 Likert items)
   - Handles missing codes (0, 9, 98, 99 → NA)
   - Derives covariates (cohort, South region, conservative ideology, membership counts)
3. **Fits three sets of OLS regression models** (all weighted by `wtssall`):
   - **Model 1:** Nationalism scale (pooled 1996/2004) with year × education interaction
   - **Model 2:** U.S. Pride scale (pooled 1996/2004) with year × education interaction
   - **Model 3:** U.S. Pride scale (2004-only) with membership effects
4. **Generates LaTeX tables** via `modelsummary()`, applying ASA formatting:
   - Omits leading zeros (`.06` not `0.06`)
   - Adds `"Note:"` prefix to significance-star legends
   - Injects `\label{tab:...}` cross-reference anchors

**Output files:** `Tabs/tbl-*.tex` (ready to `\input` into the manuscript)

## Data & Measures

### GSS Waves
- **1996:** n ≈ 2,900 respondents (pre-9/11 baseline)
- **2004:** n ≈ 2,800 respondents (post-9/11, 2004 wave)
- **Combined:** n ≈ 5,700 respondents (weighted analysis)

### Key Variables

| Outcome | Source | Construction |
|---------|--------|--------------|
| **U.S. Pride Scale** | `proud{dem, econ, genov, artsci, educ, tradeuniv, sports, parks, grp}bin` | Sum of 10 dichotomized "very proud" items (0–10) |
| **Nationalism Scale** | `{amcitizn, belikeus, ambetter, ifwrong}` | Mean of 4 reverse-coded 1–5 Likert items (higher = more nationalist) |

| Predictor | Operationalization | Notes |
|-----------|-------------------|-------|
| **Education** | `educ` (years, 0–20) | Years of formal education; missing codes (98, 99) → NA |
| **Birth Cohort** | `year - age` | Control for age effects; not a primary hypothesis |
| **Membership** (2004 only) | `memnum` (count 0–10+); `memnumcat` (0, 1–2, 3+) | Voluntary-association memberships; codes 98/99 → NA; -1 → NA |
| **Political Ideology** | `polviews` → `conservative` (0/1) | Dichotomized as 1 if `polviews` ∈ {6, 7}, else 0 |
| **Region** | `region` → `south` (0/1) | Dichotomized: 1 if `region == 3`, else 0 |
| **Sex** | `sex` (1/2) | Factor variable; reference = Male |
| **Race** | `race` (1/2/3) | Factor variable; reference = White; categories: White, Black, Other |
| **Occupational Status** | `sei` | Socioeconomic Index (0–100) |
| **Survey Weight** | `wtssall` | All models weighted by GSS sampling weight |

### Item-Level Dichotomization
All "pride" and "patriotism" items are dichotomized as:
- **1** = "very proud" (original code 1 on the GSS item)
- **0** = all other responses (don't know, not proud, somewhat proud, etc.)

See lines 41–44 of `generate_tables.R` for the mapping logic.

### Nationalism Scale Coding
The four nationalism items (`amcitizn`, `belikeus`, `ambetter`, `ifwrong`) are originally on a 1–5 Likert scale (1 = Strongly Agree, 5 = Strongly Disagree). The scale is reverse-coded via `6 - mean()` so that:
- **Higher values** = stronger nationalism (Agree tendency)
- **Lower values** = lower nationalism (Disagree tendency)

See lines 70–75 of `generate_tables.R` for the formula.

## Modeling Strategy

### Regression Models
All regression models use **ordinary least squares (OLS) with survey weights** (`lm(..., weights = wtssall)`).

#### Design 1: Pooled 1996/2004 with Year × Education Interaction
**Models 1 & 2** (Tables 1–2 in manuscript) pool the two waves and include:
- Main effects: education, cohort, year (2004 vs. 1996), sex, race, region
- **Interaction:** Year × Education (primary hypothesis test)
- **Covariates:** Occupational status (SEI), political ideology

The interaction term tests whether education's effect on national pride **differs by year**, with the hypothesis that post-9/11 (2004) shows a **larger positive effect** of education on pride.

#### Design 2: 2004-Only Cross-Sectional with Membership Effects
**Model 3** (Table 3) uses the 2004 wave only because the voluntary-association membership battery (`mem*` variables) was fielded only in 2004.

Includes main effects on U.S. Pride: education, membership category (0 vs. 1–2 vs. 3+), cohort, sex, race, region, political ideology, and occupational status.

### Model Specifications

**Outcome variables (both continuous):**
- U.S. Pride Scale: 0–10 additive count (Model 2, Table 2 & Model 3, Table 3)
- Nationalism Scale: 1–5 (reverse-coded mean); Model 1, Table 1

**Listwise deletion:** Respondents with missing values on any model variable are excluded. Missing codes on ordinal variables (education, degree, membership count, political views) are coded as NA **before** listwise deletion.

**Weighting:** All coefficients, standard errors, and model fit statistics incorporate the GSS sampling weight (`wtssall`).

## Robustness Checks & Sensitivity Analyses

### Implemented in Current Revision

1. **Listwise vs. pairwise deletion:** Not systematically compared; only listwise deletion is used in reported models.
2. **Dichotomization vs. continuous pride items:** Robustness check with non-dichotomized alternative pride scale shows r = 0.87 correlation with original and yields same substantive conclusions.
3. **1996 subsample analysis:** Political-ideology models fit on 1996 wave only (stored in `Tabs/tbl-app-political-ideology.txt` for reference; not reported in revised manuscript per Reviewer 2 Point 4).
4. **HC1 robust standard errors:** Mentioned in Analytic Strategy section as available on request.

### Acknowledged Limitations

1. **9/11 vs. wartime confound (Reviewer 1 Point 3a):** The post-9/11 period encompasses both the 9/11 attacks and the Afghanistan/Iraq wars; the two-wave GSS design cannot decompose their separate effects. This is now disclosed in Sec. 5.3 as a design limitation.
2. **Membership data (2004 only):** Model 3 is cross-sectional because the membership battery was only in 2004; no longitudinal inference possible for membership effects.

## Interpretation & Theoretical Significance

### Main Findings
1. **Education effect reversal:** Higher education predicted *lower* U.S. Pride in 1996 but *higher* Pride in 2004 (significant year × education interaction), supporting choice-process theory's prediction that autonomy-rich individuals (proxied by education) shift attachment toward the nation under threat.
2. **Nationalism patterns:** Education also shows a reversal in predicted Nationalism, though with smaller magnitudes.
3. **Membership effects:** In 2004, membership in 1–2 or 3+ voluntary associations predicted higher U.S. Pride, supporting the nested-subgroup hypothesis.

### Theoretical Implications
Results favor Lawler's (1992) choice-process theory—which links attachment to autonomy and nested group membership—over needs-based / irrational-patriotism accounts (which predict lower-education, lower-status groups would show the largest pride increases). See Sec. 5 (Discussion) of the manuscript for full theoretical interpretation.
